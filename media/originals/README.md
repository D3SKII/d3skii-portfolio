# Исходные материалы D3SKII

photos/ — фотографии выступлений и другие готовые фотографии.
videos/ — вертикальные и горизонтальные видео; сохраняйте исходное качество.
portrait-references/ — реальные портреты артиста. Сгенерированные изображения удалены.

Можно складывать материалы без предварительной сортировки: оригиналы сохраняем, производные версии подготовим отдельно. Если удобно, добавляйте в название событие или отметку club/event. Публичные контакты и сведения о мероприятиях используем только после подтверждения.
