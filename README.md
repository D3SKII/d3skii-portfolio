# D3SKII — персональное портфолио

Статический сайт без runtime-зависимостей. Главная `/` — мероприятия, `/club/` — клубное направление. Остальные направления добавляются самостоятельными страницами с общей навигацией и стилями, когда появится контент.

## Локальная работа

Из папки проекта:

```text
node scripts/build-pages.mjs
node scripts/check.mjs
node scripts/serve.mjs
```

Предпросмотр: http://127.0.0.1:4180. Сервер поддерживает byte-range запросы для перемотки видео.

## Где менять

- `profile.json` — имя и контакты.
- `scripts/build-pages.mjs` — тексты, структура и подборки страниц. После правки повторить генерацию.
- `dist/styles.css` — общий стиль и мобильные варианты.
- `dist/app.js` — видео в диалоге, закрытие, остановка и возврат фокуса.
- `dist/assets/` — только подготовленные веб-версии медиа.
- `media/originals/` — загруженные пользователем фото и видео; видео хранятся через Git LFS. На сайт попадает только dist/.

По просьбе владельца исходные материалы включены в публичный репозиторий. Для сайта используются облегчённые версии из dist/assets.

## Следующие итерации

Подтвердить выбор материалов и тексты с артистом, заменить временную подборку по мере поступления файлов, добавить реальные миксы при наличии ссылок. Сгенерированные портреты удалены по просьбе владельца. Использовать реальные фотографии. Не добавлять вымышленные кейсы, отзывы и логотипы.

## Публикация

GitHub Pages: https://d3skii.github.io/d3skii-portfolio/

Workflow .github/workflows/pages.yml публикует только dist/ при отправке в main. Сборка в Actions задаёт SITE_BASE_PATH=/d3skii-portfolio/. Локальный запуск остаётся на корневом пути /. Для получения полных исходных видео после клонирования выполнить git lfs pull.
